# Herdr model panels

## Run a panel of models

Use a pane when a participant needs a different agent binary or model vendor, the user needs to watch/take over its session, or asks for one. Equivalent in-process subagents save screen space for other participants when available. Resolve every runtime/model through the [agent workflow](agents.md).

One round asks one question. Give every participant the same self-contained brief. Start fresh agents in new panes, verify they did not resume old conversations, and use distinct names across simultaneous rounds; a name collision does not authorize reuse.

Freeze the checkout, or a named base plus the complete uncommitted diff, before dispatch and leave it unchanged through the round. Changed inputs make verdicts incomparable. Keep other participants' answers out of briefs and the working directory until comparison. The brief must prohibit reading their panes, sessions, or verdicts: exposure invalidates independent confirmation, so disclose affected results. Put outputs in this round's own directory; remove only your files, never a shared temporary root.

Ask for the complete written verdict in the pane and name what to compare; use a file only when the pane cannot return the complete answer. Dispatch the whole batch without `--wait`, confirm each delivery, then collect every assessment under the [completion contract](agents.md#complete-the-requested-outcome). A dialog in one participant must not prevent dispatch to the others.

Attribute findings and distinguish agreement/disagreement; verify material claims against primary evidence. For a discussion follow-up, quote the other positions verbatim because participants share no conversation context.
