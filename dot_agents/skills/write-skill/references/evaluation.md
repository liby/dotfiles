# Evaluation Protocol

Load before changing model-invocable routing, claimed output quality, or material global `AGENTS.md`/`CLAUDE.md` behavior.

1. Freeze baseline bytes and sanitized cases. For routing, use obvious triggers, paraphrases, near misses, and separate explicit `/name` and `$name` controls; use 8-10 of each for important skills. For global behavior, cover representative targets, adjacent no-change cases, and proportionality in every intended runtime.
2. Compare baseline and candidate against the same runtime-visible inputs. Retain the change only when target behavior improves with no paired regression; rerun nondeterministic boundaries when cost permits.
3. For output-quality claims, compare the same cases with and without the skill. Assertions that pass in both are regression controls, not evidence of skill value; investigate assertions that fail in both.
4. For routing, capture the complete catalog when confidentiality permits. Otherwise disclose exclusions, label the result a managed-catalog proxy, and add realistic runtime probes. Count `invoked` only when the full `SKILL.md` loads; label classifier-only output `selected`.
5. Keep a validation split hidden and try fresh prompts before accepting an important rewrite. Revise the general intent or boundary when a case fails. If a run skips a linked file, sharpen the pointer's load condition before inlining it.
